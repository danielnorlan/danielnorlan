# Daniel Norlan

Software engineer in Vestfold, Norway.

- **Software Engineer at [Usbl](https://www.usbl.no/).**
- **Co-founder and CTO of [Noragentic](https://noragentic.com/)**, an AI company in
  Forskningsparken in Borre. I built ICP Hub, Noragentic's B2B sales platform.
- **Creator of Varden Turnus**, an algorithmic roster planner for Norwegian healthcare.
  It started as our bachelor project in computer engineering at the University of
  South-Eastern Norway (USN), *Algoritmisk turnus i kommunal helsetjeneste*, which won
  the jury's first prize (Fagjuryens 1. pris) at USN Expo 2026.

I trained as a nurse before I became a computer engineer (USN, 2026).
